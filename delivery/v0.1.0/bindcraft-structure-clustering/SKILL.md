# 结构聚类与结果分析

只处理用户请求的阶段：输入检查、已有结果核查、聚类、代表结构选取或可视化。用户要求先分析、不动手时只读检查，不运行计算、不修改文件；不因检查重跑已有结果或提交作业。输入数据、算法参数和结果路径以当前用户任务为准，示例不是默认输入。没有提供执行所需输入时说明缺项；不要假定它们是已有项目的数据。

## 核心约束

- 按用户要求确认结构链、命名映射、评分字段含义和依赖；已有结构目录的 `.pdb` 只读取第一层，CSV 不会筛选 PDB。输入命名不兼容时先报告，不猜测映射。
- 当前方法默认采用 TM-score **0.5**，用户可指定其他值。每对分数是 TMalign 两个长度归一化分数的算术平均；按 `Average_dG` 升序选择中心，以成员对中心分数达到阈值归簇。同簇非中心成员不要求两两达标。具体适用性与字段定义需结合数据核对。
- 主要簇默认成员数 **≥5**，与聚类阈值不同，用户可调整。代表结构建议总数 **100**，可调整，不自动沿用既有配额；不足时说明并让用户确定处理方式。实际配额根据本次簇及需求单独准备或确认。
- 用户需要建议配额时使用 `scripts/suggest_quota.py`，默认按当前主要簇大小的平方根比例分配，每个纳入的簇至少保留一个中心；生成建议表后明确说明分配方法与总数，允许用户修改，不把建议称为最优方案。配额不满足容量或中心保留约束时停止并说明，勿静默调整总数或纳入范围。
- 明确记录本次输入、参数、输出和各阶段依赖关系；不要把新聚类与旧矩阵、旧配额或旧名单混用。第三张图应核对名单数、匹配数、展示范围内的匹配数，不以名单总数代替红圈匹配数。
- 不默认上传结构、启动 BindCraft 或上游筛选、提交集群任务、覆盖结果或移动删除用户数据；按用户实际请求及环境操作。
- 聚类与计算评分不证明实验结合；代表选取不是分子动力学模拟。区分真实运行、已有结果核对与尚未验证的情况。

## 按任务读取

- 新使用者、换数据或环境准备：先读 [references/setup.md](references/setup.md) 与 [references/own-data.md](references/own-data.md)。仅配置显式路径和参数，无需编辑配套脚本；配置清单不是自动读取的配置文件。

- 查输入、执行或核查聚类：读取 [references/workflow.md](references/workflow.md) 和 [references/inputs-outputs.md](references/inputs-outputs.md)。
- 代表选取或画图：读取 [references/workflow.md](references/workflow.md) 和 [references/methods.md](references/methods.md)，核实实际脚本的路径和输出行为。
- 配套 Python 脚本位于本 Skill 的 `scripts/`，使用 [references/commands.md](references/commands.md) 中的参数接口；从当前 Skill 文件位置定位脚本，不依赖作者的教程目录或研究数据。TMalign 和 Python 依赖需在实际环境准备，缺项应明确指出。

汇报使用的输入、关键参数、各输出路径、验证结论及未执行或未验证的环节。不要把示例中的 1052 个结构、27 簇或 100 条名单当作其他数据的预期结果。
