# 输入输出与一致性检查

## 输入

- PDB：已准备的复合物结构；确认 binder 链及目录层级。当前主脚本只读取目录第一层小写 `.pdb`。
- CSV：设计名与 `Average_dG`。当前主脚本按 `design_name`, `Design`, `Name`, `description`, `Description` 的顺序选择第一个存在的列；匹配时去掉 PDB 末尾 `_chainX`、`_model数字` 等并归一化，重复键使用最后一行。不同来源应核对命名和评分语义，不随意推断。
- TMalign：与运行系统兼容的独立可执行程序；确认路径和运行环境，不能以 TMscore 替代。

## 聚类输出

| 文件 | 用途 |
| --- | --- |
| `binder_chain_<链>_pdbs/` | 提取的链 |
| `global_tm_matrix.csv` | 全局两两平均 TM-score，对称且对角线为 1 |
| `clusters.csv` | 成员、所属簇、中心、评分和与中心相似度 |
| `centers.csv` | 各簇中心和成员数 |
| `clustering.txt` | 后续选取和绘图使用的文本 |
| `cluster_pairwise_tm_matrices/` | 至少两个成员的簇内矩阵；单成员簇无矩阵 |

检查成员数量、名称唯一性、中心与成员一致性、簇大小之和、矩阵名称及尺寸、阈值条件；对已有文件只做与任务相符的读取。评估所用精度，勿混淆文本显示的四位小数与矩阵精度。

## 选取和绘图

当前选取配额表使用 `cluster_id` 与 `recommended_n_for_MD`。配额需与本次实际簇匹配，未列出的簇被跳过并提示。验证矩阵覆盖候选成员、配额及输出数量。当前主要簇图和全部簇图的解析 CSV 保存全部解析成员，不等于每张图实际显示的成员集合。

本 Skill 的第三张图通过 `--selected` 显式读取名单，不会自动寻找或替换旧名单。核对输入聚类、矩阵、配额和名单的对应关系。未知或重复名单报错；展示范围以外的已匹配结构会计入总匹配，但不计入图例红圈数。当前示例的 `Average_dG` 对应 Rosetta `dG_separated`（REU）；其他数据需先确认评分来源、含义及单位。前两张图保留来源的横轴标题，改变评分来源时须先明确是否适用。
