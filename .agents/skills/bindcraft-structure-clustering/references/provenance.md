# 来源、验证与分发范围

本包版本为 0.1.0，整理日期为 2026-11-11，供私下交付与试用。Skill 来源于作者已有结构聚类教程及参数化 Skill；本轮封装保留七个 Python 文件、SKILL.md、界面配置和其余方法文档的原始字节，只更新本来源说明，并在 Skill 目录外补充使用与安装文档。

## 方法及输入

主聚类脚本按平均 TM-score 和 Average_dG 升序实施中心优先的贪心聚类；选取脚本固定各簇中心，再按 TM 距离实施 Kennard–Stone 式选取；三份绘图脚本显示全部簇、主要簇、主要簇与已选结构。suggest_quota.py 提供有上下限的平方根比例配额，output_guard.py 保护已有输出。默认阈值 0.5、主要簇至少 5 个成员、建议选取 100 个，均可调整。

使用者提供自己的 PDB、评分表和兼容的 TMalign。正式 Skill 不包含作者研究数据、测试样例、第三方程序、生成结果或本机维护记录，也不依赖这些材料。路径和名称规则见 own-data.md，逐阶段命令见 commands.md。

## 已完成验证

2026-11-11，版本对应的七个 Python 文件在 Codex 托管云环境完成技术流程验收：9 个 Cα-only 结构、36 对实际 TMalign 比对、3 个三成员簇、6 个代表结构和 3 张图。测试特意使用 min-n=1、total=6，正式默认值保持不变。发布后新任务复测，以及同一托管实例内全新代码目录的依赖安装、TMalign 编译和完整计算均通过。

完整验证摘要和范围见交付包根目录 VALIDATION.md；逐文件 SHA256 见 MANIFEST.json 和 SHA256SUMS.txt。作者维护的原始测试证据单独留存，不作为运行依赖。

这些结果验证了指定技术样例和环境；不等同于新机器部署、平台安装钩子生命周期或任何新研究数据的验证，也不证明实验结合。requirements.txt 是未固定版本的运行依赖表，实际环境应先做输入与依赖检查。
