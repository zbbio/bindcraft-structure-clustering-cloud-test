# 工作流

1. 根据用户请求选择只读检查、已有结果复核、聚类、选取或作图。已有结果足够时不重跑比对；不因用户要求检查而执行计算或产生正式结果。
2. 明确本次输入、用户选择的链、参数、所用工具、输出目录及预计工作量；参数未知时区分约定默认和需要用户确认的信息。仅当用户要求实际执行时才运行计算，按照用户指定或安全的新目录保存，防止覆盖。
3. 阶段之间以本次结果的实际路径衔接。新运行的聚类、全局矩阵、配额和名单相互对应；不要因脚本默认值而复用示例。配套选取与叠加图已通过参数指定路径，无需编辑源码。使用外部旧版脚本前应核对接口，不把它与本交付版混用。
4. 检查本次输入及产出，报告各阶段数量、路径、使用的阈值、已执行的命令与验证状态。输入或运行失败时明确停止下游工作，保留不完整结果以供用户处理，不声称已完成。

## Skill 配套脚本

使用本 Skill 的 `scripts/`，不依赖作者教程路径。具体命令见 [commands.md](commands.md)。输入路径相对启动命令的工作目录，建议明确指定绝对路径；脚本资源相对于当前 Skill 目录定位。用户须准备自己的 PDB、CSV、配额和工具，Skill 不捆绑研究数据或 TMalign。

主聚类脚本与来源算法保持一致；选取脚本要求显式指定聚类文本、矩阵、配额和输出；三份绘图脚本也要求或支持显式路径。所有脚本输出都须是新目录或新文件，父目录预先准备好，不静默覆盖。选取和叠加图没有作者数据的默认路径。主要簇叠加图默认最小成员数 5，可通过参数调整；严格报告匹配数，未知或重复名单会报错。

需要建议配额时可运行 `suggest_quota.py`，使用本次 `centers.csv`；默认总数 100、最小成员数 5。纳入的每簇至少分配 1 个名额，不超过该簇成员数；未纳入的簇输出配额 0，便于明确其未参与选取。输出是供审阅或修改的建议表，不触发结构选取；建议与实际选取分开记录。用户明确要求完整分析并接受默认建议时，可按该配置继续，但须报告实际参数和配额；用户仅要求建议时停在建议表。

## 代表选取和成本

默认建议总数 100，仅在需要代表结构而用户没有指定时提出。根据用户要求和现有簇制定或确认配额，确保非负整数、不超过簇成员数、明确未覆盖的簇与目标总数；如果候选总量不足 100，说明情况并让用户确认选取数量。用匹配当前聚类的完整矩阵与名单；检查重复、缺失、匹配及实际选中数。

不上传用户研究数据。输入 N 个结构需要 N(N-1)/2 次两两比对；需要计算时先告知规模及实际执行位置。无需全流程时只执行所需步骤。使用集群时遵照用户请求和实际环境；不把语法检查或本机运行说成服务器成功。
